# 🚨 Ultrasonic Distance Alarm System

An Arduino-based security and obstacle detection system using the HC-SR04 ultrasonic sensor, a LED, and a Buzzer. When an object gets too close to the sensor, the system triggers a visual (LED) and audible (Buzzer) alarm.

## 🛠️ Components Used
* **Arduino Board** (Uno / Nano)
* **HC-SR04** Ultrasonic Distance Sensor
* **Buzzer** (Audio Alarm)
* **LED** (Visual Indicator)
* **Breadboard & Jumper Wires**

## 💻 How to Use
1. Connect the components as shown in the circuit diagram.
2. Open `sketch_oct14a.ino` in the **Arduino IDE**.
3. Select your board and port, then click **Upload**.
4. Test the distance sensor by moving an object closer!
